Offensive Security

Understanding mechanisms down to the byte level

I am an offensive security practitioner focused on penetration testing, low-level development, and binary analysis. My approach relies on active hands-on methodology—breaking down complex targets, understanding how systems work internally, and learning how to exploit vulnerabilities safely and effectively.

I regularly practice reverse engineering and exploit development using C, Python, and Assembly (x86/x64). Through hands-on platforms like Hack The Box Academy, pwn.college, and OpenSecurityTraining2 (OST2), I consistently build skills across memory corruption, custom protocol analysis, and offensive automation.

I maintain structured notes and document technical processes to refine my workflows. Building custom tools and analyzing low-level code allows me to bridge the gap between offensive techniques and system security defense.

My technical roadmap is geared toward mastering network and Active Directory penetration testing, working toward CPTS certification, and expanding my expertise in binary exploitation.
